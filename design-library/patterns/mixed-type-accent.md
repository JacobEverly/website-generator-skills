# Pattern: Mixed Typography Accent

A single contrasting typeface (script, serif, or handwritten) used for **one element** in the hero — typically a tagline, qualifier, or brand modifier — while the rest of the page stays in a disciplined sans-serif system.

## Why It Works

- Creates instant personality without compromising the overall system
- The contrast makes both typefaces feel more intentional
- One accent font is sophisticated; two+ is chaos
- Breaks the "everything is Inter" monotony that plagues developer sites

## How to Use

- Pick ONE element: tagline, brand qualifier, or emotional hook
- Use a script/serif/handwritten face at a smaller size than the heading it accompanies
- Give it an accent color (not the primary text color)
- Never use the accent font for headings, body, nav, or UI elements

## Reference: Dreamcash Hero

```
"Trading made fun"     ← massive geometric sans, near-black
  "*on Hyperliquid"    ← handwritten script, brand blue, smaller
```

The script tagline adds warmth and playfulness to an otherwise clean, confident headline. It signals "we're serious but not boring."

## Good Accent Font Pairings

| Primary (sans) | Accent (script/serif) | Vibe |
|---|---|---|
| Inter / DM Sans | Playfair Display (italic) | Editorial, sophisticated |
| Plus Jakarta Sans | Caveat | Casual, approachable |
| Geist | Instrument Serif | Technical but warm |
| Inter | Newsreader (italic) | Authoritative with personality |

## Rules

- Max 1 accent font per site
- Only used 1-3 times on the entire page (hero + maybe closing CTA)
- Always smaller or equal size to the primary heading it accompanies
- Always a different color than the primary text
- Never on buttons, nav, metadata, or body text
